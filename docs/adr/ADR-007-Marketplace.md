# ADR-007

## Title

Marketplace Strategy

## Status

Proposed

## Decision Date

2026-10-20

---

## Context

Langfristig sollen Themes und Erweiterungen einfach installierbar sein.

---

## Decision

Zuerst werden APIs entwickelt.

Marketplace-Funktionen werden erst nach Version 1.x betrachtet.

---

## Reihenfolge

1. Theme API
2. Plugin API
3. Marketplace

---

## Consequences

### Positive

- Saubere Architektur
- Geringeres Risiko

### Negative

- Marketplace kommt später
